# OrçaZap

Ferramenta simples desenvolvida para **uso próprio no trabalho**, com o objetivo de agilizar a criação de orçamentos.

A aplicação recebe os dados copiados do sistema, organiza os produtos em um carrinho e gera um orçamento formatado para envio pelo WhatsApp.

## Tecnologias

* HTML
* CSS
* JavaScript

## Objetivo

Reduzir o trabalho manual de organizar e formatar orçamentos durante o atendimento.
